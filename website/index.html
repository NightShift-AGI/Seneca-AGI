Experience Seneca AGI

Launch the Streamlit interface locally, connect your preferred LLM backend, and begin a guided Stoic dialogue.

  1. Install dependencies with pip install -e .
  2. Start Ollama or your preferred backend
  3. Run streamlit run app.py

Desktop bundles for Windows, macOS, and Linux

Create native bundles on each operating system with PyInstaller. Builds are self-contained and run the Streamlit UI with a desktop-friendly launcher. Visit the download page for release links and setup steps.

Install bundling tools

Use the optional bundle extras to install PyInstaller.

pip install -e ".[bundle]"

Build the bundle

Run the build helper on your target OS. Output appears in dist/.

python packaging/build.py
Builds must be created on each platform. macOS apps may require signing and notarization before distribution.
